# Codex 输入栏统计 3.0.1

修复发行版后台无法连接部分正在使用中的官方客户端窗口、导致控件持续不显示的问题。

固定 websocket-client 到经过旧插件及实际客户端验证的 1.8.0。1.9.2 在受影响的真实窗口中握手即被关闭；相同端点、相同嵌入式 Python 使用 1.8.0 可正常收发 CDP 请求。端点通信显式绕过本机代理，官方客户端的 API 和网络设置不变。

桌面入口与 MCP 入口统一使用已安装缓存中的控制器，避免从两个路径启动时错误报告后台已断开。

已装 3.0.0 的用户直接运行 3.0.1 安装器，安装到原目录。首次从旧 `@personal` 版迁移的用户仍需先移除旧插件。安装后使用 **Codex 官方版（输入栏统计）** 入口。

运行环境和安装方式与 3.0.0 相同，保留聊天、登录、提供方配置和统计样本。仍采用 MIT 协议，安装器尚未做 Authenticode 签名。
