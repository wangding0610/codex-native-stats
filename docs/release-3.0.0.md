# Codex 输入栏统计 3.0.0

首次 Windows x64 可安装发行版，按 MIT 协议开源。适用于微软商店版 Codex 官方客户端，提供输入栏中的会话统计、累计 Token、当前/最大上下文和悬停详情。

- Windows 安装器自带 Python 3.13.16、Node 22.23.3 和固定版本依赖，无需管理员权限。
- GitHub 仓库提供 `codex-stats` 插件市场；插件 ID 为 `codex-native-stats@codex-stats`。
- 支持插件开关、按版本升级、安装失败回滚和卸载；保留官方客户端、登录、聊天与统计样本。
- 保留官方客户端更新机制，动态发现当前商店包，兼容 MSIX 的端点文件重定向。
- 安装器创建 **Codex 官方版（输入栏统计）** 启动入口。首次安装请保存任务、正常退出 App 一次，再使用此入口。

如果已安装旧 `@personal` 版，请先保存任务、正常退出 Codex，并移除旧插件，再安装公开发行版。

验证：16 项实际发行流程检查通过，包括中文路径、MCP 持续连接、重复安装、运行期间升级/卸载、损坏包拒绝、数据和配置保留。另有 4 项安装器检查、12 项启动回归检查、11 项生成速度检查；在官方客户端 26.930.2377.0 的隔离配置中通过 24 个界面场景及切换/重载/重新连接检查，并通过真实 Explorer 启动的端点发现检查。界面场景使用合成记录和提问卡片，不等同于所有真实账号场景。

下载 `CodexStats-Setup-3.0.0-windows-x64.exe` 安装。`CodexStats-3.0.0-windows-x64.zip` 提供完整运行文件；`SHA256SUMS.txt` 用于校验下载完整性。

GitHub 市场的真实下载、启用、MCP 加载、卸载和配置保留共 5 项检查通过。中文快捷方式使用 Unicode ShellLink 接口，兼容英文 Windows。

此版本未做 Authenticode 签名。挂载使用本地 renderer 端点，不是官方输入栏扩展 API；未来客户端界面变化可能需要插件适配。统计数据不是计费账单。
